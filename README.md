# busanganda — 부산 명소 지도 🗺️

부산의 명소를 지도에서 보고, 두 장소 사이의 거리를 재고, 나만의 명소를 등록할 수 있는 웹앱이에요.
컴퓨터와 휴대전화의 인터넷 브라우저(크롬, 엣지, 사파리 등)에서 쓸 수 있어요.

## 할 수 있는 일

- **지도 보기**: 처음 열면 부산이 보이고, 해운대해수욕장 · 광안리해수욕장 · 감천문화마을에 핀이 꽂혀 있어요.
- **핀 누르기**: 핀을 누르면 장소 이름과 위도 · 경도가 나와요.
- **거리 재기**: 장소 두 곳을 고르면 지도에 점선이 그어지고 거리가 km와 m로 나와요.
  - 하늘에서 일직선으로 잰 거리예요. 자동차나 걸어서 가는 길의 거리와는 달라요.
- **나만의 명소**: 이름을 쓰고 지도를 클릭해 위치를 고른 뒤 저장해요. 고치거나 지울 수도 있어요.
  - 저장한 장소는 브라우저를 껐다 켜도 남아 있어요. (브라우저 안에 저장돼요)

## 내 컴퓨터에서 실행하는 방법

### 준비물: Node.js 설치하기 (처음 한 번만)

1. <https://nodejs.org> 에 들어가요.
2. **LTS**라고 쓰인 버튼을 눌러 내려받고, 설치 파일을 열어 **다음(Next)** 만 계속 눌러 설치해요.

### 1단계: 명령어 창 열기

- **윈도우**: 시작 버튼 → `PowerShell` 검색 → 실행
- **맥**: `command + 스페이스` → `터미널` 검색 → 실행

### 2단계: 명령어를 하나씩 입력하기

명령어를 한 줄씩 붙여 넣고 **Enter**를 눌러요.

| 순서 | 명령어 | 하는 일 |
|---|---|---|
| ① | `node -v` | Node.js가 잘 설치됐는지 확인해요. `v22.x.x` 같은 숫자가 나오면 성공! |
| ② | `git clone -b claude/exciting-darwin-fszrme https://github.com/kongee-lee/busanganda.git` | 앱 파일을 내 컴퓨터로 복사해 와요. |
| ③ | `cd busanganda` | 복사해 온 앱 폴더 안으로 들어가요. |
| ④ | `npm install` | 앱에 필요한 부품(지도 도구 등)을 내려받아요. 1~2분 걸릴 수 있어요. |
| ⑤ | `npm run dev` | 앱을 켜요. |

> `git`이 없다고 나오면: GitHub 저장소 화면에서 브랜치를 `claude/exciting-darwin-fszrme`로 바꾸고
> 초록색 **Code** 버튼 → **Download ZIP** 으로 받아 압축을 푼 뒤, 명령어 창에서 그 폴더로 들어가 ④번부터 하면 돼요.

### 3단계: 브라우저로 열기

⑤번을 하면 `Local: http://localhost:5173/` 라는 글자가 나와요.
브라우저 주소창에 **http://localhost:5173** 을 입력하면 앱이 열려요.

- 앱을 끄려면 명령어 창에서 `Ctrl + C` 를 눌러요.
- 다음에 다시 켤 때는 ③번(`cd busanganda`)과 ⑤번(`npm run dev`)만 하면 돼요.

### 휴대전화로 보기 (컴퓨터와 같은 와이파이일 때)

`npm run dev` 대신 `npm run dev:phone` 을 입력하면 `Network: http://192.168.x.x:5173/` 같은 주소가 나와요.
이 주소를 휴대전화 브라우저에 입력하면 돼요.

## 확인용 명령어

- `npm test` : 거리 계산과 장소 저장 · 수정 · 삭제가 잘 되는지 자동으로 검사해요.
- `npm run build` : 인터넷에 올릴 수 있는 완성 파일을 `dist` 폴더에 만들어요.

## 파일 구성

```
index.html                화면의 뼈대
src/main.js               지도, 거리 재기, 장소 등록 화면 동작
src/style.css             디자인 (컴퓨터 · 휴대전화 화면 모두)
src/data/defaultPlaces.js 예시 장소와 처음 지도 위치
src/lib/distance.js       위도·경도로 직선거리 계산 (하버사인 공식)
src/lib/placeStore.js     장소 저장(localStorage) · 수정 · 삭제 · 중복 검사
tests/                    자동 테스트
```

지도는 [Leaflet](https://leafletjs.com)과 [OpenStreetMap](https://www.openstreetmap.org)을 사용해요. API 키가 필요 없어요.
